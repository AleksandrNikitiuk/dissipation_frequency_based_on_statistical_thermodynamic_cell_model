# Dissipation Frequency Based on Statistical Thermodynamic Cell Model

This repository contains MATLAB code for analyzing and optimizing parameters of a statistical thermodynamic cell model. It investigates dissipation processes using the Nelder-Mead optimization method and Monte Carlo simulations.

## 📁 Repository Contents

- `analyze_cell_dissipation.m` — Main script for running the model and performing optimization.
- `cell_shear_exper_data.mat` — Experimental data for shear stress analysis.
- `.gitattributes` — Git configuration file.

## ⚙️ Requirements

- MATLAB R2020 or newer  
- Optimization Toolbox  
- Statistics and Machine Learning Toolbox

## 🚀 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/AleksandrNikitiuk/dissipation_frequency_based_on_statistical_thermodynamic_cell_model.git
   ```

2. Open MATLAB and navigate to the project directory.

3. Run the main script:
   ```matlab
   analyze_cell_dissipation
   ```

The script loads experimental data, optimizes model parameters, and analyzes dissipation behavior based on the statistical thermodynamic approach.

## 📊 Method Overview

This model uses statistical thermodynamics to simulate the behavior of a cell under shear stress. It applies the Nelder-Mead simplex method for optimization and Monte Carlo simulations to evaluate dissipation frequency and variability.
